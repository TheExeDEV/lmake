# Support

## Documentation

The [README](README.md) describes the preprocessor directives, the require conversion rules, every `lmake.json` setting
and the command line. The [changelog](CHANGELOG.md) lists what changed in each release.

## Questions and problems

- Found a bug? Open a [bug report](https://github.com/TheExeDEV/lmake/issues/new?template=bug_report.yml) with the smallest
  source file that shows it.
- Missing a feature? Open a [feature request](https://github.com/TheExeDEV/lmake/issues/new?template=feature_request.yml).
- Security problems go through [security advisories](https://github.com/TheExeDEV/lmake/security/advisories/new), see
  [SECURITY.md](SECURITY.md).

When asking for help, include the output of `lmake version`, your `lmake.json` and the `.luaurc` files involved.
